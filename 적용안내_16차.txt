1. 무엇이 바뀌었나
------------------
[1] 시작 화면이 언제나 먼저 뜬다
    주소에 부문이 적혀 있어도 건너뛰지 않는다. 대신 그 부문 카드를 맨 앞으로
    옮기고 "이어보던 부문" 띠를 붙인다. 누르면 보던 자리(표준화 방법·지도 색
    기준·펼친 서랍)를 그대로 되살린다.

[2] 통계창에서 탭을 없앴다
    탭 세 개는 세 가지를 같은 무게로 늘어놓는 장치라, 부문 종합이 주라는 것을
    화면이 말해 주지 못했다. 이제 이 차례로 쌓는다.

        흐름줄
        선택 지역        ← 지도에서 고른 곳이 있을 때만, 늘 맨 위
        부문 종합        ← 본문. 접히지 않고 펼쳐져 있다
        표준화 민감도    ← 서랍(접힘 상태로 시작) · 카드 5장
        원데이터         ← 서랍(접힘 상태로 시작) · 카드 4장

[3] 시군구를 클릭하면 그 지역이 맨 위로 올라온다
    선택 지역 칸이 통계창 맨 위에 생기고 부문 종합은 접힌다. 통계창은 자동으로
    맨 위로 감긴다. 접힌 부문 종합 머리를 누르면 다시 펴지고, "선택 해제"를
    누르면 원래대로 돌아간다.

[4] 원데이터를 별도 서랍으로 뺐다
    부문 종합과 같은 자리에 두지 않는다. 표준화 민감도도 같은 방식이다.

[5] 글자 크기를 8단으로 통일했다
    화면 곳곳에 흩어져 있던 크기 20종을 :root의 --fs-1 ~ --fs-8 여덟 개로
    모았다. 앞으로 크기를 바꿀 일이 있으면 styles.css 맨 위 그 여덟 줄만
    고치면 된다. 실측 결과 화면에 실제로 쓰인 크기는 6종이다.

[6] 깨지던 표식을 도형으로 바꿨다
    지도 색 기준 칸의 − + ◆ 와 닫기 ✕ 는 글꼴 문자였다. 그 문자가 없는 글꼴이
    걸리면 빈 네모로 나왔다. 전부 SVG 도형으로 다시 그렸다(Glyph.jsx).
    부문 아이콘(PNG)은 원래 문제가 없어 그대로 둔다.

[7] 주소 규칙
    서랍 상태를 d 키에 적는다 (d=sens / d=raw / d=sens.raw).
    v2.0의 t(탭) 키는 더 이상 읽지 않는다. t가 적힌 옛 링크는 무시하고 기본
    상태로 연다.


2. 적용 방법
------------
이 압축을 풀면 나오는 src/ 와 docs/ 를 저장소 같은 자리에 덮어쓴다.

    cd ~/Desktop/연구실/국토연_web/SSI
    (풀어 놓은 폴더의 src, docs 를 이 자리에 덮어쓰기)
    npm run build
    cp dist/index.html docs/index.html

docs/index.html 은 이미 이번 빌드 결과가 들어 있어, 그대로 쓸 거라면 위
빌드 두 줄은 건너뛰어도 된다.
