SSI 17차 패치 — 적용 안내
================================================================

무엇을 고쳤나
----------------------------------------------------------------

[1] 시작 화면에서 부문을 고르면 언제나 '1 지표 선택'부터 시작한다.

    16차에서는 주소(해시)에 적힌 부문을 다시 고르면 '이어보기'로 보고
    곧장 3단계(지도 색 기준)로 뛰었다. 그래서 부문을 고르자마자 조작부가
    아래로 감겨 내려가, 무엇을 골라야 하는지가 아니라 색 고르는 칸이
    먼저 보였다.

    이제 어느 부문을 고르든 단계는 항상 1로 시작하고, 통계창은 접혀 있다.
    이어보기는 '되살리기'만 한다 — 표준화 방법·지도 색 기준·선택 지역·
    산점도 축은 링크에 담긴 대로 두되, 단계만 1로 되돌린다. 지표를
    확인하고 넘어가면 그 자리에 그대로 이어진다.

[2] 지도를 누르기 전에도 전국 통계가 곧바로 나온다.

    부문 종합 맨 위에 있던 '지도에서 시군구를 클릭하면…' 안내 상자를
    없앴다. 통계창을 열자마자 보이는 첫 칸이 통계가 아니라 안내문이라,
    전국 통계(분포 요약 · 상위·하위 열 곳 · 시도별 평균 · 지표별 기여도)가
    아래로 밀리고 화면은 아직 아무것도 없는 것처럼 보였다.

    같은 안내는 흐름줄 한 줄로 이미 하고 있으므로 상자는 뺐다.
    지도에서 시군구를 누르면 선택 지역 칸이 맨 위로 올라오는 동작은
    그대로다.

[3] 서랍 두 개(표준화 민감도 · 원데이터)를 처음부터 펴 둔다.

    16차에서는 접은 채로 시작했는데, 그러면 방법별 분포 · 방법 간 순위
    이동(범프 차트) · 표준화 민감도 산점도 · 순위 이동이 큰 시군구 ·
    지표 간 산점도가 화면에서 통째로 사라진 것처럼 보였다.

    차례(본문이 먼저, 서랍이 나중)와 머리 모양만으로도 무엇이 주(主)인지는
    충분히 드러나므로 접어 감출 이유가 없다. 접고 펴는 것은 그대로 된다.

[4] 조작부(왼쪽 300px 칸) 글자 잘림.

    · 부문 이름 옆에 '지표 N개 · 2023년'이 붙어 '공간구조 효' 처럼
      이름이 잘리던 것 → 이름이 제 칸을 다 쓰고, 모자라면 뒤엣것이
      아랫줄로 내려간다.
    · '지금 Min-Max · 수식과 범위는 통계창 표준화 민감도 칸에…' 안내가
      칸 밖으로 새던 것 → 칸 안에서 접힌다.
    · 아직 오지 않은 단계(sb2-lock), 다음 단계 단추(sb2-next),
      2단계 안내문(sb2-hint) 세 곳은 그동안 CSS 규칙이 아예 없어
      브라우저 기본 글꼴(Arial 13.33px)로 나오고 있었다 → 글자 크기
      여덟 단에 맞추고, 잠긴 칸은 흐리게 잠가 둔다.

[5] 지도 범례의 분류 방식 단추가 잘리던 것.

    자동 · 등간격 · 분위수 · 자연분류 · 표준편차 다섯이 148px 한 줄에
    들어가지 않아 '…자연분류 표준' 에서 끊겼다 → 두 줄로 접는다.

[6] 순위 이동이 큰 시군구 목록.

    · 긴 시도 이름(강원특별자치도)이 시군구 이름을 밀어내던 것 →
      시도를 이름 아래 한 줄로 내렸다.
    · 맨 오른쪽 계단 값(29.5)이 칸 밖으로 밀려 잘리던 것 → 숫자 칸
      둘을 고정폭으로 빼고 이름·막대가 남은 자리를 나눠 갖는다.
    · 표 머리 'Min-Max → 백분위순위'가 잘리던 것 → '간격 → 등수'로
      줄이고, 정확한 방법 이름은 마우스를 올리면 나온다.

[7] 표준화 방법 눈금띠의 오른쪽 끝 표식이 띠 밖으로 반쯤 나가 있던 것,
    카드 부제가 낱말 가운데서 끊기던 것('누르면 지도에서 선 / 택됩니다')
    → 둘 다 고쳤다.

[8] 주소(해시) 규칙이 하나 뒤집혔다.  ※ 옛 링크 주의

    d = '접어 둔 서랍'.  서랍은 기본이 펼침이라, 기본 상태에서는 d가
    아예 붙지 않는다.  (16차의 d 는 반대로 '펼친 서랍'이었다.)

        d 없음        → 둘 다 펼침 (기본)
        d=sens        → 표준화 민감도만 접음
        d=raw         → 원데이터만 접음
        d=sens.raw    → 둘 다 접음

    16차 이전에 만들어 둔 링크의 d 는 뜻이 반대가 된다. 그 외 키
    (s m k r c p i x y)는 그대로다. 아주 옛날의 t(탭) 키는 읽지 않고
    무시한다.


계산은 손대지 않았다
----------------------------------------------------------------
지표 방향 반전, 네 가지 표준화(Min-Max · 거리기반 · 백분위순위 ·
로지스틱), 동일가중 평균, T점수(평균 50 · 표준편차 10), 부문 민감도
(SSI = |Min-Max 순위 − 백분위순위 순위|) — 어느 것도 바꾸지 않았다.
이번 패치는 전부 화면과 흐름에 관한 것이다.


적용하는 법
----------------------------------------------------------------
압축을 풀고 아래 파일을 SSI 폴더에 덮어쓴다.

    src/App.jsx
    src/styles.css
    src/components/CenterPanel.jsx
    src/components/PickedSummary.jsx
    src/components/SensitiveList.jsx
    src/components/MethodDetail.jsx
    docs/index.html          ← 다시 빌드한 결과물(깃허브 페이지용)
    v17.cjs                  ← 확인 스크립트(선택)

docs/index.html 은 이미 빌드해 둔 것이므로, 그대로 쓰면 다시 빌드할
필요가 없다. 소스를 더 고친 뒤에는

    npm run build
    cp dist/index.html docs/index.html

를 다시 해 주면 된다.


확인
----------------------------------------------------------------
v17.cjs 는 79가지를 확인한다 (현재 0 FAIL).

    npx playwright install chromium      (한 번만)
    npm run build
    npx http-server dist -p 8099         (또는 python3 -m http.server 8099 --directory dist)
    node v17.cjs

확인 항목 요약
    D1  시작 화면에서 부문을 고르면 언제나 1 지표 선택부터
    D2  조작부 글자가 칸 밖으로 나가거나 잘리지 않음
    D3  지도를 누르기 전에 전국 통계가 곧바로 (안내 상자 없음)
    D4  서랍 두 개가 처음부터 펴져 있어 차트가 다 보임
    D5  화면 전체(지도 범례 · 통계창 카드 포함) 글자 잘림 없음
    C1~C13  16차 확인 항목 (해시 규칙 C12 는 [8] 대로 바뀌었다)
